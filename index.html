COS30045 Week 4 Lab SVGs and D3: data binding and bar charts

Week 4 Lab — SVGs and D3

Six exercises, each kept as its own page so every step can be seen on its own. Exercise 4.1 draws an SVG by hand; 4.2 to 4.6 build a D3 bar chart step by step from television registration data processed in KNIME.

4.1 SVG house and garden

An initial drawing, then a customised one using shapes, paths, text, groups, transforms and styling, with a switchable coordinate overlay.

4.2 Manipulate and add elements

A separate JS file uses D3 to restyle existing elements and append paragraphs and SVG shapes.

4.3 D3 set up

The 4.2 code removed; a responsive container, an SVG with a viewBox, and a test rectangle.

4.4 Load data from CSV

d3.csv() with a row conversion function, the result in the console, and D3 summary functions.

4.5 Binding and drawing with data

One rectangle per brand via selectAll().data().join(), widths from the data, bars spaced out.

4.6 Scaling charts

A linear scale for counts, a band scale with padding for brands, and labels.

Data

data/tvBrandCount.csv — the number of television models per brand, produced by the KNIME workflow knime/2026 TV Data.knwf from the Energy Rating register (tv_2026_02_15.csv, data.gov.au): keep available models sold in Australia, lower-case brand names, merge "samsung electronics" into "samsung", count models per brand, and keep brands with 20 or more. 25 brands, 4,240 models.
